# 分組討論工具

一個單純 HTML 檔案製作的分組討論工具，適合課堂、工作坊或團隊活動使用。
操作者可以勾選實際出席成員，指定分組組數，快速產生隨機分組與小組長，
並有討論倒數計時等機制。

## 功能

- 預設提供 12 位成員，可自行修改名單。
- 可勾選或取消勾選出席成員。
- 可在畫面上即時新增成員，且會避免重複名稱。
- 自訂分組數量（1–20 組）。
- 自訂討論時間（1–120 分鐘）。
- 以隨機方式分組，並盡可能平均分配成員。
- 每組會自動隨機抽選一位發言人。
- 分組完成後顯示討論計時器；預設延遲 10 秒開始倒數。
- 可點擊計時器重新開始討論倒數。
- 支援桌面與行動裝置版面。
- 不需安裝套件，也不需要後端或網路連線。

## 使用方式

1. 使用瀏覽器開啟 [`grouping-tool.html`](./grouping-tool.html)。
2. 勾選本次活動的出席成員。
3. 需要時輸入名稱並按「新增」。
4. 設定組數與討論時間。
5. 按下「開始分組」。
6. 查看分組結果、發言人與討論倒數。

按下「清空」會恢復預設組數、討論時間、出席狀態與初始畫面。動態新增的成員只存在於目前頁面，重新整理後會消失。

## 自訂預設成員

編輯 `grouping-tool.html` 中的 `defaultNames` 陣列：

```javascript
const defaultNames = [
    'Annie',
    'Bill',
    'Carey'
];
```

## 分組規則

工具會先將勾選的成員隨機洗牌，再依序輪流放入各組，因此各組人數差距最多為 1。出席人數不可少於指定組數。

## 技術資訊

- CSS
- Vanilla JavaScript
- 使用瀏覽器原生 `setInterval` 與 `setTimeout` 實作倒數及動畫效果

## 注意事項

- 成員名單、分組結果與計時狀態都只存在瀏覽器目前頁面，不會儲存至伺服器。
- 若指定組數大於出席人數，工具會提示錯誤並停止分組。
- 重新整理頁面會恢復原始預設成員與設定。
